# Tarefa 02 — Criar a arena de teste

Só executar depois de o Milestone 0 estar concluído.

Lê `AGENTS.md` e `docs/`.

Cria uma arena de teste 3D simples com:

- chão com colisão;
- quatro limites ou paredes com colisão;
- DirectionalLight3D;
- WorldEnvironment simples;
- ponto de spawn do jogador;
- câmara temporária apenas se for necessária para visualizar a arena.

Usa apenas primitivas e recursos internos do Godot.

Não cries ainda movimento, jogador funcional, inimigos, armas ou UI.

Mantém a cena organizada e documenta quaisquer passos que tenham de ser feitos no editor.

Atualiza `docs/PROGRESS.md`, valida o projeto e termina com comandos Git específicos.
