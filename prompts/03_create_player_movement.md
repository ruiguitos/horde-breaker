# Tarefa 03 — Criar jogador e movimento

Só executar depois de a arena de teste estar concluída.

Lê `AGENTS.md` e `docs/`.

Implementa um jogador provisório com:

- raiz `CharacterBody3D`;
- forma visual simples;
- `CollisionShape3D`;
- movimento WASD;
- gravidade;
- velocidade exportada;
- movimento relativo ao mundo nesta primeira versão;
- spawn dentro da arena.

Confirma ou cria as ações:

- `move_forward`
- `move_backward`
- `move_left`
- `move_right`

Não implementes ainda:

- câmara controlada pelo rato;
- salto;
- disparo;
- animações;
- stamina;
- XP;
- armas;
- Mixamo.

Usa GDScript tipado e mantém o script pequeno.

Atualiza `docs/PROGRESS.md`, explica como testar e termina com comandos Git específicos.
