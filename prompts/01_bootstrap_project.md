# Tarefa 01 — Preparar o projeto

Lê `AGENTS.md` e todos os documentos em `docs/`.

Depois:

1. inspeciona todos os ficheiros existentes;
2. identifica a versão/configuração do Godot através do projeto;
3. confirma se existe `project.godot`;
4. confirma o estado do Git sem apagar ou reverter alterações;
5. cria apenas a estrutura mínima necessária para o Milestone 0;
6. cria uma cena de arranque mínima e segura, caso ainda não exista;
7. define essa cena como main scene, caso seja necessário;
8. garante que o projeto arranca sem scripts de gameplay prematuros;
9. atualiza `docs/PROGRESS.md`;
10. valida com Godot headless se o executável estiver disponível.

Não cries ainda:

- jogador;
- movimento;
- câmara;
- zombies;
- armas;
- UI;
- Autoloads;
- save;
- XP;
- modelos Mixamo.

Antes de alterar ficheiros, apresenta o estado encontrado e os ficheiros que pretendes tocar.

No final, apresenta:

- resumo;
- ficheiros alterados;
- passos manuais no editor;
- como testar;
- resultado da validação;
- problemas encontrados;
- próximo passo;
- comandos Git específicos, sem executar o commit.
